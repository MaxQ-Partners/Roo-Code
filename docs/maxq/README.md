# MaxQ Roo Fork — Documentation

This directory contains documentation specific to the MaxQ fork of Roo Code.
Upstream Roo never writes to this directory, so merges from upstream will
not touch these files.

- **`BUILD-AND-RELEASE.md`** — How to build the extension, install it, and
  cut a new MaxQ version.
- **`UPSTREAM-SYNC.md`** — How to pull in changes from upstream Roo without
  losing MaxQ customizations.
- **`CHANGELOG.md`** — MaxQ-specific change log (separate from upstream's).
- **`sprints/`** — Sprint plans for MaxQ-specific changes.

When in doubt, start with `BUILD-AND-RELEASE.md`.
